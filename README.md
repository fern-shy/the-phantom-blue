# the phantom blue

A 3×3 wall of white tiles. Drop audio files onto tiles; hover a tile and its loop swells in, move on and it blends into the next.

**Run it:** double-click `index.html` (Safari or Chrome). Fully offline, single file, no install. Click *enter* (browsers need one click before audio).

- **Drop** audio on a tile (several files at once fill empty tiles in name order). × on hover clears.
- **Hover** = that tile swells (swell time), the others release (release time). The last hovered tile keeps playing when the cursor leaves the wall.
- **master / tone** (low-pass) to tuck it under the band. **drift** wanders between tiles when idle. **space** = hush (fade out/in). **f** = fullscreen.
- Files: WAV/MP3/M4A/FLAC work everywhere; AIFF only in Safari. For seamless loops use WAV and a different (odd) length per tile so they drift against each other.
- Files are not remembered between reloads (re-drop them).
